# ELMIN ROYALE

Mobile-friendly browser gameplay prototype.

## Current features
- Three troop cards with different elixir costs and damage
- Elixir regeneration
- Tower health and a simple victory condition
- Responsive layout for phones

## Publish with GitHub Pages
In the repository, open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.

## Important
This is a local single-player prototype. It is not yet real-time multiplayer, does not have a production server or player accounts, and does not send or award Pi. Multiplayer requires an authoritative game server, matchmaking, persistence and anti-cheat checks. Any Pi integration must be implemented and reviewed separately using official Pi Platform requirements.
